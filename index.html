Methylome Signatures for PRRT Response in GEP-NETs

Author: Farnoosh Abbas Aghababazadeh
Contact: farnoosh.abbasaghababazadeh@uhn.ca

A reproducible whole-genome EM-seq analysis pipeline for investigating DNA methylation signatures associated with response to peptide receptor radionuclide therapy (PRRT) in gastroenteropancreatic neuroendocrine tumors (GEP-NETs).

Workflow

FASTQ → fastp → bwa-meth → BAM merge / duplicate marking → methylation QC → CpG calls → CpG matrix → 300-bp matrix

| Step | Analysis | Output | Status | | --- | --- | --- | --- | --- | | 01–03 | FASTQ inventory, QC and trimming | Validated, trimmed FASTQ pairs | Implemented | | 04–05 | hg38 alignment | Sorted and indexed BAMs per FASTQ pair | Implemented; cohort running | | 06 | Library merge and duplicate marking | Duplicate-marked, indexed BAM per library; QC | Tested; additional libraries running | | 07 | Alignment and methylation-bias QC | QC statistics, M-bias profiles | Initial validation underway | | 08 | CpG methylation extraction | Per-library CpG methylated/unmethylated counts | Planned | | 09 | Cross-sample CpG matrices | CpG beta, count and coverage matrices | Planned | | 10 | 300-bp genomic windows | Regional beta, coverage and CpG-count matrices | Planned |

The workflow runs on HPC4Health (H4H) using Slurm. Versions above reflect the tools identified in the current H4H workflow; fastp and downstream analysis-runtime versions must be recorded from the installed environment. M-bias QC must be reviewed before final CpG extraction.

See data processing and output specifications for sample/library hierarchy, QC requirements and matrix definitions.

Setup

This repository uses Pixi for its declared environment:

git clone https://github.com/wanglab-cns/mgnet-methylome.git
cd mgnet-methylome
pixi install

Cluster-specific tools and reference files may require H4H modules or separately staged resources; see the repository documentation. Installing Pixi alone does not necessarily install the cluster's bioinformatics tools.
